# Revisión comunitaria del Wayuunaiki

## Estado de esta versión

COSTA VIVA 0.5.10 incorpora una traducción provisional completa de la interfaz al Wayuunaiki.

No debe considerarse una traducción validada. Puede contener errores de vocabulario, gramática, variantes dialectales, ortografía y adecuación cultural. Su finalidad es disponer de una primera versión completa que pueda ser revisada directamente con hablantes Wayuu y expertos locales.

La interfaz muestra un aviso permanente cuando se activa WY.

## Principio de trabajo

La revisión local tiene prioridad sobre este borrador. Si una persona hablante considera que una expresión no se entiende, suena extraña o existe una forma local más adecuada, debe registrarse la corrección.

No se pretende fijar desde fuera una terminología definitiva.

## Fuentes de apoyo utilizadas

Se utilizaron como apoyo vocabulario documentado en el Diccionario básico ilustrado Wayuunaiki Español y Español Wayuunaiki de David M. Captain y Linda B. Captain, además de materiales educativos bilingües disponibles públicamente.

Entre los términos documentados utilizados como base están anaajawaa para guardar, e'rajawaa para observar, ayaawataa y ayaawajaa para medir, achajawaa para buscar, ayaakua para fotografía, wopu para camino, miichi para casa, ashajaa para escribir, akalia para fecha y oora para hora.

Las frases completas de esta versión son un borrador de trabajo y no se atribuyen al diccionario ni a sus autores.

## Cómo revisar

El archivo WAYUUNAIKI_REVIEW.csv contiene las 388 cadenas de interfaz.

Para cada fila se recomienda marcar una de estas situaciones

- CORRECTO
- SE ENTIENDE PERO SE DICE DE OTRA MANERA
- INCORRECTO
- NO HAY ACUERDO TODAVÍA

Añadir la propuesta local y, cuando sea pertinente, la comunidad o zona donde se usa esa forma.

## Regla de publicación

Hasta concluir la revisión comunitaria, COSTA VIVA debe seguir mostrando que WY es una versión provisional en revisión local.
